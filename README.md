# Calc

A small browser calculator — three files, no build step, no dependencies.

## Files
- `index.html` — structure
- `style.css` — styling
- `script.js` — calculator logic

## Run it
Just open `index.html` in a browser. No server or install needed.

## Good for practicing Git
This is a nice second repo to practice with because it has multiple files,
so you can try things like:
- Editing just `script.js` and committing only that change
- Adding a new operator (e.g. square root) on a branch, then opening a PR
- Using `git diff` to see exactly what changed before committing
